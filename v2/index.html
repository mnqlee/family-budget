📖 Setup & help

Everything you need to update the app, sync with your wife, and keep your data safe. Your household code and database URL are at the bottom.

⬆️ Deploy a new version

  1. Download the new index.html from your chat.
  2. Open your GitHub repo → the v2 folder (family-budget/v2/).
  3. Delete the old index.html there, then upload the new one. Commit the change.
  4. Wait about a minute for GitHub Pages to rebuild.
  5. On your phone, fully close the tab and reopen mnqlee.github.io/family-budget/v2/ — or pull down to hard-refresh.
Your budget data is stored separately from the code, so replacing the file never wipes your numbers.

☁️ Connect Firebase (sync both phones)

Get your database URL
  1. Go to console.firebase.google.com → open your existing project.
  2. Left menu → Build → Realtime Database.
  3. Copy the URL at the top (https://…firebaseio.com). No database yet? Tap Create Database → pick a location → locked mode → then copy the URL.
Set the security rules
  1. In Realtime Database, open the Rules tab.
  2. Paste the rules below and tap Publish.
{
  "rules": {
    "hb5": {
      "$household": {
        ".read": true,
        ".write": true
      }
    }
  }
}
This scopes access to the app's own hb5/ branch — your v1 app's data is untouched. The 6-digit code is the lock. Want real sign-in instead? Ask in chat.

🏠 Create your household

  1. Tap the LOCAL / #code chip at the top → Leave household on this device → confirm. It reloads to setup.
  2. Choose Sync with Firebase.
  3. Paste your database URL, enter your name, tap Create new household.
  4. It shows a 6-digit code — that's your family key. Save it (screenshot or readiness vault).
  5. Now enter income, envelopes, and bills. Do this on Firebase before entering real numbers — local data doesn't move to the cloud.

💑 Add your wife

  1. On her phone, open mnqlee.github.io/family-budget/v2/.
  2. Setup screen → Sync with Firebase.
  3. She pastes the same database URL, enters her name, types the 6-digit code in the Join box, taps Join.
  4. Done — anything either of you logs appears on the other phone in about a second.
  5. Optional: on her phone, Settings → Language → ES for Spanish. It's per-device; yours stays English.

🛟 Keep it safe

  • The top-right dot is green when synced; grey/red means offline — writes queue and catch up automatically.
  • Settings → Export JSON backup now and then. Cheap insurance.
  • Whoever creates the household holds the original code — don't lose those 6 digits.
